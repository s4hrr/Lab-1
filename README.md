# Лабораторная работа №1 — Вариант 4

Задание: [ITMOPython-2022/Lab-1](https://github.com/ITMOPython-2022/Lab-1)

Вывод в консоль построен на ANSI escape-последовательностях.

## Вариант 4

| Пункт | Значение |
|---|---|
| Страна | Польша |
| Узор | d |
| Функция | y = x^0.5 |
| Условие | Среднее по модулю первых 125 и вторых 125 чисел |

## Что реализовано

1. **Флаг Польши** — белая полоса сверху, красная снизу (`\033[48;2;R;G;Bm`).
2. **Узор d** — плитка 12×4 символа, замощается по горизонтали и вертикали.
3. **График y = x^0.5** — первая четверть, поле 10×40 символов с осями.
4. **Диаграмма по `sequence.txt`** — среднее по модулю двух половин последовательности в процентах.
5. **Допзадание** — анимация из 3 кадров развевающегося флага с очисткой консоли через `os.system`.

## Результат

```
Среднее по модулю, числа 1-125  : 4.8595
Среднее по модулю, числа 126-250: 5.1501

1-125     48.55%
126-250   51.45%
```

## Запуск

```bash
python main.py
```

Файл `sequence.txt` должен лежать рядом с `main.py`.

Цвета используют режим TrueColor. Стандартный `cmd.exe` его не поддерживает —
нужен Windows Terminal, PowerShell 7 или любой терминал Linux/macOS.
